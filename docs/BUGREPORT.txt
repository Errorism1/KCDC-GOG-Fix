=== 2. Identity for non-Steam players (feature request) ==============================================

With the client fixed, a GOG player reaches the server, passes the build verification, downloads
resources and loads the level. A server resource then kicks the player because connection.steamId is
empty ("SteamID64 fehlt. Bitte über Steam verbinden."). GOG has no Steam id and no Epic id.
Request: some identity for GOG players (e.g. GOG Galaxy account id), or documentation for server
owners on how to admit players without a Steam id (name: whitelist entries, Epic/GOG ids).
